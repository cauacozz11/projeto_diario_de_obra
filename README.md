# Voicivil

Voicivil é uma plataforma web voltada para a área de Engenharia Civil que tem como objetivo facilitar o registro e acompanhamento das atividades realizadas em obras.

A proposta do sistema é simplificar o **diário de obra**, permitindo que responsáveis pela execução registrem atividades do dia utilizando **áudio ou texto**, e que essas informações sejam organizadas automaticamente em relatórios claros e estruturados.

## Principais funcionalidades

- Cadastro de usuários
- Cadastro de obras
- Planejamento de tempo de projetos/obras
- Registro de atividades realizadas via áudio ou texto
- Transcrição de áudio para texto
- Geração de relatórios diários em PDF organizados e simplificados
